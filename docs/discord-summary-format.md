# Discord 週次サマリー フォーマット仕様

週次 cron で送信する「今後のライブ予定」サマリーメッセージのフォーマット。

---

## 構造

```
▍ Week N  M/D (曜) 〜 M/D (曜)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📅 YYYY/MM/DD (曜)
─────────────────────────────
🎤 <グループ名>
　📍 <会場名>（<都道府県>）
　🕐 OPEN HH:MM ／ START HH:MM
　👥 <出演者1> / <出演者2>        ← 共演者がいる場合のみ
　🎫 <チケットサイト名>  <URL>  💴 ¥<金額>

🎤 <グループ名>                   ← 同日に別ライブがある場合
　...

📅 YYYY/MM/DD (曜)
─────────────────────────────
...

▍ Week N+1  M/D (曜) 〜 M/D (曜)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

...

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🆕 新規 N件　✏️ 更新 N件　📆 YYYY/MM/DD 時点
```

---

## ルール

### 週区切りヘッダー
- `▍`（U+2590 左太縦棒1文字）で始める。複数文字の枠線は描画崩れの原因になるため使わない。
- `Week N` の N は送信時点からの相対週番号（Week 1 = 直近の週）。
- 範囲は `月曜〜日曜` ではなく、**その週に含まれる最初〜最後のイベント日**で表示する。
- 週ヘッダーの直後に `━━━` の区切り線を入れる。

### 日付ブロック
- 同日の複数ライブは日付ヘッダーを共有し、`🎤` ごとに縦並びにする。
- `─────` の区切り線は日付ごとに1本入れる。

### イベント行
| 行 | 必須 | 条件 |
|----|------|------|
| `📍 会場（都道府県）` | ◎ | 常に表示 |
| `🕐 OPEN HH:MM ／ START HH:MM` | ○ | START のみ判明している場合は `START HH:MM` のみ |
| `👥 出演者リスト` | △ | 共演者がいる場合のみ表示 |
| `🎫 サイト名  URL  💴 ¥金額` | ○ | 未確定の場合は `🎫 チケット情報未確定` |

### フッター
- メッセージ末尾に `━━━` 区切り線を置き、新規件数・更新件数・集計日を1行で表示する。

---

## 実装メモ

- Discord の1メッセージ上限は 2000 文字。件数が多い場合は週単位で分割して送信する。
- URL はそのまま貼ると Discord がプレビューを展開するため、`<URL>` で囲んでプレビューを抑制することを検討する。
- 送信タイミング: 毎週月曜 09:00 JST を基準とする（cron: `0 0 * * 1` UTC）。
